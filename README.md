# Bulgarian mythology tarot

Двуезичен (БГ/EN) сайт за самопознание с таро, вдъхновено от българската митология.

## Стартиране

Изисква Node.js 22 или по-нов.

```bash
npm install
cp .env.example .env
npm start          # http://localhost:3000
npm test
```

Първото стартиране създава базата (`data/tarot.db`), попълва я със съдържание по подразбиране и генерира заместващи изображения в `uploads/defaults/`.

## Как работи

- Цялото съдържание (текстове, изображения, шрифтове, алгоритми) се чете от SQLite и от папката `uploads/`. В кода на сайта няма твърдо записан текст.
- `GET /api/public/config` връща заглавията, фона, текста на холограмата, Intro и Privacy.
- `POST /api/analyze` и `POST /api/analyze/pdf` смятат анализа на сървъра по дата и пол.
- Алгоритмите са кодови модули `module.exports = function(input) { return output }`, изпълнявани в изолирана среда (`isolated-vm`: без файлове и мрежа, лимит 500 ms и 32 MB).
- PDF се генерира с `pdfkit`, шрифт DejaVu с пълна кирилица (`assets/fonts`).

## Файл със съдържание (пренос на съдържанието)

Всички текстове, изображения, шрифтове, алгоритми и таблици могат да се пренасят като един JSON файл (`tarot-content`, версия 2):

```bash
npm run content:export -- съдържание.json                 # записва сегашното съдържание на сайта
npm run content:import -- съдържание.json --dry-run       # само проверка, нищо не се записва
npm run content:import -- съдържание.json                 # зарежда
```

Зареждането е „всичко или нищо“: целият файл се проверява (типове изображения по съдържание, размери, шрифтове, ключове, алгоритмите се изпълняват в изолираната среда), чак тогава се записва. Форматираният текст се почиства от скриптове, а заменените алгоритми запазват предишната си версия в базата.

## Алгоритми

- **Основен:** `reduce(n)` сумира цифрите, докато n ≤ 22. A=ден, C=месец, E=година, G=A+C+E, I=A+C+E+G, e2=E+I, x2=(e2+G+I)+e2, всичко редуцирано до 1–22. Число 22 е аркан „0 Глупакът“. Воден знак: арканът на x2.
- **Гуа:** слънчева година (преди 4 февруари се ползва предишната), сума на последните две цифри, формули по пол и век, Гуа 5 става 2 (мъж) или 8 (жена). В PDF се показват само четирите посоки.
- **Зодии:** елемент по дата; жена получава Кралица, мъж получава Крал.

## Внедряване

Зад reverse proxy с HTTPS (nginx, Caddy). Архивирай `data/` и `uploads/`.
